# Jev for Gmail

**한국어** | [English](README.en.md)

Gmail 받은편지함의 **기본(Primary) 탭** 메일 옆에 우선순위 점수 배지를 표시하는 크롬 확장 프로그램입니다.
점수는 [TypeSafe](https://typesafe.ai)의 **Jev** 모델이 매깁니다. Jev는 텍스트를 생성하지 않고, 정해진 질문에 확률과 점수로 답하는 모델입니다.

A Chrome extension that shows a priority score next to each email in Gmail's Primary inbox, using TypeSafe's Jev model. Gmail data is never modified.

## 점수 계산

메일마다 Jev에게 네 가지를 묻습니다.

| 질문 | 형태 |
|---|---|
| 내가 직접 해야 할 일이 있는가 | 확률 0~1 |
| 얼마나 급한가 | 0~3 |
| 내 업무에 얼마나 중요한가 | 0~3 |
| 이미 회신했거나 처리했는가 | 확률 0~1 |

**우선순위 = 0.4 × 할 일 + 0.3 × 급함/3 + 0.3 × 중요도/3**. 이미 처리된 것으로 보이면 그만큼 감점합니다.

| 배지 | 의미 |
|---|---|
| 빨강 | 0.7 이상 |
| 주황 | 0.5 ~ 0.7 |
| 회색 | 0.3 ~ 0.5 |
| 연회색 | 0.3 미만 (광고, 뉴스레터 등) |
| 초록 점선 ✓ | 이미 처리된 것으로 판단 |
| 🔒 | 환자 관련 또는 개인정보 메일: 전송하지 않음 (마우스를 올리면 이유 표시) |

배지에 마우스를 올리면 항목별 값이 보입니다.

## 개인정보와 안전

- **안전 검사를 통과한 메일 제목과 최신 본문 최대 2,500자가 TypeSafe 서버(미국)로 전송됩니다.** 사용 전 소속 기관의 개인정보 규정을 확인하세요.
- **명확한 고위험 정보가 있는 메일은 전송하지 않습니다.** 환자 시술·수술 일정, 입원대기·환자 명단, `등록번호+생년월일+진단명` 형태의 환자 표, 사용자가 지정한 환자 메일 발신자, 명시된 환자명·환자 ID, 주민번호·카드번호·실제 계좌번호·여권번호·인증정보가 발견되면 🔒 처리합니다.
- `환자`, `외래`, `participant`, `입금`, `계좌`, `주소` 같은 일반적인 업무 단어만으로는 메일을 잠그지 않습니다. 이메일·전화번호·주소·생년월일과 일반 번호는 브라우저 안에서 가린 뒤 전송합니다.
- TypeSafe 요청에는 raw 발신자 이름이나 이메일을 넣지 않습니다. 발신자는 브라우저 안에서 `organization_internal`, `academic_organization`, `journal_platform`, `automated`, `external` 중 하나로 분류됩니다.
- Gmail thread의 `From`, `To`, `Cc`, `Bcc`, `Reply-To` 등 주소 헤더는 브라우저 안에서 `[SELF]` 또는 `[REDACTED]`로 치환합니다. 본문과 제목의 이메일, 전화번호, 생년월일, 주민번호, 카드번호, 계좌·여권·환자 ID, 주소, 비밀번호·ID 값도 가립니다. 외부 이름 탐지 API는 사용하지 않습니다.
- masking 후 별도 안전 검사를 한 번 더 수행합니다. 이메일·전화·주민번호·카드·계좌·여권·주소·환자 ID 등 위험 패턴이 남으면 해당 메일 전체를 🔒 처리하고 전송하지 않습니다.
- 이름·소속 대신 설정에서 고른 비식별 역할만 전송합니다. 내 이메일 주소 설정은 thread에서 내 답장을 `[SELF]`로 치환하는 로컬 처리에만 사용하며 TypeSafe로 전송하지 않습니다.
- `already_handled` 판단은 `[SELF]` 표식, 마감 경과 여부, 브라우저에 보관된 후속 확인 메일 규칙을 사용합니다.
- 🔒 배지에 마우스를 올리면 설정에서 제외한 발신자, 환자 ID, 계좌번호 등 구체적인 잠금 원인이 표시됩니다.
- **필터는 완벽하지 않습니다.** 걸러지지 않은 메일에 개인정보가 남아 있을 수 있습니다.
- Gmail의 메일, 라벨, 읽음 상태는 바꾸지 않습니다. 화면에 배지만 추가합니다.
- API 키는 각자의 브라우저(`chrome.storage.local`)에만 저장됩니다.
- 이 도구는 의료기기나 임상 판단 도구가 아닙니다. 점수는 읽는 순서를 정하는 참고용입니다.

## 설치

1. 이 저장소에서 **Code → Download ZIP**을 눌러 받은 뒤 압축을 풉니다. 설치 후 폴더를 옮기거나 지우면 안 됩니다.
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램 로드** → 압축을 푼 폴더(`manifest.json`이 있는 폴더) 선택
5. 자동으로 열리는 설정 화면에서 입력하고 저장 → **연결 테스트**
   - TypeSafe API 키 ([console.typesafe.ai/keys](https://console.typesafe.ai/keys)에서 발급)
   - 비식별 역할 (의료인·임상연구자, 연구자 등)
   - 내 이메일 주소 (로컬 `[SELF]` 치환 전용)
   - 환자 관련 메일 발신자 (등록한 주소의 메일은 모두 잠김. `@도메인`은 해당 도메인 전체를 잠그므로 신중히 사용)
6. Gmail을 새로고침하면 받은편지함 기본 탭에 점수가 표시됩니다.

툴바 아이콘을 누르면 배지 켜기/끄기, 점수 캐시 지우기, 설정 열기를 할 수 있습니다.

## 동작 범위

- 받은편지함 **기본 탭**, **최근 7일** 메일만 채점합니다.
- 한 번 채점한 메일은 브라우저에 저장해 다시 보내지 않습니다 (새 답장이 오면 다시 채점).
- 개인정보 필터 정책이나 관련 설정이 바뀌면 이전 정책의 잠금 캐시는 자동으로 무효화됩니다.
- 비용: 메일 1통당 약 $0.0001 (각자의 TypeSafe 크레딧에서 차감).
- 본문은 Gmail 인쇄용 보기에서 가져오며, 헤더 제거·masking·최종 안전 검사 후 최신 부분 최대 2,500자만 전송합니다. 읽음 상태는 바뀌지 않습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 및 언어 선택 (Manifest V3) |
| `_locales/ko`, `_locales/en` | 한국어·영어 화면 문구 |
| `content.js` | Gmail 목록 읽기, 환자 메일 필터, 배지 표시 |
| `background.js` | Jev API 호출, 질문 정의 |
| `options.html/js` | API 키 등 설정 화면 |
| `popup.html/js` | 툴바 팝업 |
